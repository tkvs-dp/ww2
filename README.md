# 二戰檔案館｜The Second World War (1939–1945)

> 一份翻開的黃褐色解密檔案，以照片、文字與規格數據，帶你重回人類史上規模最大的世界大戰。

- 🌐 **線上檔案庫**：[https://tkvs-dp.github.io/ww2/](https://tkvs-dp.github.io/ww2/)
- 📁 **專案原始碼**：[https://github.com/tkvs-dp/ww2](https://github.com/tkvs-dp/ww2)

本站是專為中學生設計的行動優先（Mobile-First）靜態歷史網站，視覺風格融合泛黃公文紙、紅色解密印章與打字機字體，將龐雜的第二次世界大戰史料整理為結構分明、隨手可查的檔案庫。

---

## 🗂️ 檔案室收錄內容

- **五大章節大事時間軸（30 則重大事件）**：劃分「壹・開端（1937–1939）」、「貳・閃電戰（1939–1941）」、「參・時間轉折（1941–1943）」、「肆・反攻（1944）」至「伍・結局（1945）」。
- **重大戰役專冊（15 場關鍵戰役）**：從 1939 年波蘭戰役、中途島海戰、諾曼第登陸到 1945 年柏林戰役，綜觀戰略攻守轉折。
- **人物檔案（21 位歷史關鍵人物）**：收錄德、英、美、蘇、日、法、義、中華民國等 8 國領袖、軍事將領與密碼學家。
- **武器圖鑑（24 款陸海空裝備）**：涵蓋槍械、裝甲、航空、艦艇與火砲 5 大類型，包含詳細規格數據與研發背景。

### 互動特色
- **點擊相片解密檔案（Dossier Modal）**：點選任一戰役、人物或武器卡片，相片將以流暢飛入動畫展開為「已解密」卷宗，內附詳細生平或規格參數，並支援「上一份／下一份」快速切換。
- **時間軸墨線與印章標記**：捲動時間軸時，歷史墨線隨進度延伸，走過的事件節點會被塗黑；首頁大綱中的重點事件則以紅色節點與「重點」標籤標示。
- **信鴿傳令兵（回到頂部）**：畫面右下角常駐信鴿圖標，向下捲動時會探頭打招呼，點擊後振翅起飛並平滑滑回頂部。
- **雙重條件即時篩選**：武器圖鑑支援「國籍」與「類型」即時交叉篩選；時間軸事件附有跨冊關聯標籤，可一鍵直達對應檔案。
- **網址錨點（Hash Linking）**：每份戰役、人物與武器皆擁有專屬 ID（例如 `battles.html#normandy`），複製網址即可直接分享特定檔案。

## 🔍 自主學習探索任務

閱讀時不妨試著帶著問題翻閱檔案，答案都能在網站中找到：

1. **戰略轉折**：1942 年在太平洋戰場（海戰）、東線蘇德戰場（陸戰）與北非戰場，各自發生了哪三場扭轉戰局的關鍵戰役？
2. **科技與密碼**：在英國人物檔案中，艾倫·圖靈（Alan Turing）與布萊切利園的團隊如何破解德軍恩尼格瑪密碼機（Enigma）？
3. **軍工與戰術**：比較蘇聯 T-34 戰車與德國虎式戰車的設計思維——厚重裝甲高火力 vs. 大規模量產與傾斜裝甲，對戰局產生了什麼影響？

## 📖 歷史閱讀筆記：數據與批判性思考

戰史中記錄的軍民傷亡人數（如全戰估計逾 7,000 萬人死亡、1 億人被動員）與戰果數據多為歷史學界常用的估計值。不同交戰國家的官方檔案、學者估算或解密紀錄常有些微出入。閱讀歷史檔案時，建議抱持求證與批判思考態度，多方比對不同來源的史料。

## 💻 本地預覽與專案結構

對網頁製作有興趣的同學，可以下載原始碼並在資料夾內透過終端機啟動本機伺服器：

```bash
# 在專案目錄下執行 Python 內建 HTTP 伺服器
python3 -m http.server 8000
```
瀏覽器開啟 `http://localhost:8000` 即可預覽。

### 檔案結構概覽
- `index.html`：檔案館首頁（戰事速報跑馬燈、數據統計、章節摘要與前線照片膠卷）。
- `timeline.html` / `battles.html` / `people.html` / `weapons.html`：各主題展示頁。
- `credits.html`：照片出處、作者與授權說明頁。
- `data.js`：歷史資料核心庫（30 則事件、15 場戰役、21 位人物、24 款武器全由此維護）。
- `app.js`：介面互動邏輯（信鴿動態、解密卷宗彈窗、時間軸墨線捲動計算）。
- `credits.js`：72 張歷史圖片的 Wikimedia Commons API 詮釋資料。
- `styles.css`：復古檔案紙質、打字機風格與響應式排版樣式。
